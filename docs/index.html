Six phases

Use the links for background, then try the exercise on this tower.

01 Design 02 Python 03 Blender 04 OpenFOAM 05 Water test 06 Grow

Phase 01

Sketch the tower

Follow the water from the reservoir to the top distributor and back.

  • Watch Chris Loh’s original tower build
  • Read Oklahoma State’s tower guide

Try it. Draw a side view and label the tower height, pipe diameter, planting pockets and high and low reservoir levels. Mark any dimensions you still need to measure.

Save a dimensioned sketch and input list.

Phase 02

Work out the pump duty

Use Python to estimate how much head the pump needs at different flow rates.

  • Watch Microsoft’s lesson on Python functions
  • Watch Grundfos find and read a pump curve

Try it. Start with a function that converts L/min to m³/s. Then calculate static lift and pipe losses at a few flows, using both reservoir levels.

Save the system curves and a candidate duty point from a real pump curve.

Phase 03

Model it in Blender

Turn the sketch into a model you can inspect from the inside.

  • Watch Blender’s modelling introduction
  • Read Blender’s guide to scene units

Try it. Set the scene to metric. Model the tower and reservoir to size, then make one pocket and duplicate it at the spacing from your sketch.

Save an editable Blender file and a cutaway view.

Phase 04

Explore air–water flow

Learn how OpenFOAM tracks a moving water surface before modelling the tower.

  • Watch a modified dam-break setup
  • Follow the OpenFOAM dam-break tutorial

Try it. Run the example for your OpenFOAM version and view the water surface in ParaView. Then sketch a smaller case around the tower distributor and a few pockets.

Save your tutorial case and a plan for measuring wetting in the tower model.

Phase 05

Test with plain water

Check whether the physical tower behaves as your calculations predicted.

  • Watch Chris Loh’s follow-up build
  • Open the project’s measurement sheet

Try it. Collect and time the pump discharge. Check each pocket for wetting, then switch off the pump and watch how much water drains back.

Save measured flow, wetting notes and any changes the tower needs.

Phase 06

Start growing

Once the water test passes, start with a few plants and see how their roots change the flow.

  • Explore Minnesota Extension’s home hydroponics lessons
  • Read Oklahoma State’s EC and pH guide

Try it. Log reservoir level, EC, pH and root growth. Record top-ups and recheck whether water reaches each pocket as roots fill in.

Save a growing log and a routine based on your observations.
